## F.1 Abkürzungen

| Abkürzung | Bedeutung |
|---|---|
| AAR | anlagenseitiger Anschlussraum (Zählerplatz) |
| AFDD | Fehlerlichtbogen-Schutzeinrichtung (Arc Fault Detection Device) |
| APZ | Abschlusspunkt Zählerplatz (Feld im RfZ) |
| DBO | Installationsverteiler für die Bedienung durch Laien (DIN EN 61439-3) |
| FFB | fertiger Fußboden |
| HAK | Hausanschlusskasten |
| HES | Haupterdungsschiene |
| IuK | Informations- und Kommunikationstechnik |
| LAR / MLAR | (Muster-)Leitungsanlagen-Richtlinie |
| LS | Leitungsschutzschalter |
| NAR | netzseitiger Anschlussraum (Zählerplatz) |
| NAV | Niederspannungsanschlussverordnung |
| ONT | Optical Network Termination (Glasfaser-Modem) |
| PEN | kombinierter Schutz- und Neutralleiter |
| POP | Power Frequency Overvoltage Protective Device (DIN EN 50550) |
| RCBO | FI/LS-Schalter |
| RCD | Fehlerstrom-Schutzeinrichtung |
| RDC-DD | Einrichtung zur Erkennung von Gleichfehlerströmen (in Ladeeinrichtungen) |
| RfZ | Raum für Zusatzanwendungen (Zählerplatz) |
| RuK | Rundfunk und Kommunikation |
| SLS | selektiver Leitungsschutzschalter (Hauptleitungsschutzschalter) |
| SPD | Überspannungs-Schutzeinrichtung (Surge Protective Device) |
| TAB | Technische Anschlussbedingungen des Netzbetreibers |
| TAR | Technische Anschlussregel (VDE-AR-N 4100) |
| TE | Teilungseinheit (Verteiler) |
| TOV | temporäre (netzfrequente) Überspannung |
